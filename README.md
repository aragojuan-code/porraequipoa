# Porra Equipo A — Starter

Primera entrega funcional:

- Landing pública.
- Registro con Supabase Auth.
- Login.
- Dashboard privado.
- Crear porra privada.
- Entrar con código después de login.
- Ver miembros de la porra.
- Estética retro de misión.
- Loop musical propio generado por Web Audio, sin usar música original protegida.

## Archivos

- `supabase_schema.sql`: ejecutar en Supabase SQL Editor.
- `index.html`: interfaz principal.
- `styles.css`: estilos.
- `app.js`: lógica de frontend.
- `config.example.js`: copiar como `config.js` y rellenar Supabase URL + anon key.

## Pasos

1. Crear o abrir proyecto Supabase.
2. Ejecutar `supabase_schema.sql`.
3. Copiar `config.example.js` a `config.js`.
4. Rellenar:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
5. Subir archivos a GitHub.
6. Conectar repo a Vercel.
7. Configurar dominio `porraequipoa.naojaguar.com`.
